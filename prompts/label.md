# 라벨 프롬프트 — 블라인드 정답 (v0, 작성 예정)

> 담당: U. 노션 「구매 의도 지식 베이스 설계」 5-4절 기준. 수정 이력은 이 파일의 커밋 기록으로 남는다.

## 입력 (서버 ③ 단계가 받는 수준으로만)
- 상품 목록
- 가구 유형 (있으면)
- 캘린더 태그와 도착일 기준 날짜 (예: "도착 2일 뒤 토요일, 생일")

만들 때의 의도는 절대 넣지 않는다.

## 출력 (JSON)
- 의도 id (목록에서, 묶음 2개 주문은 2개)
- 의도 문장
- 의도에 속하는 물건 묶음
- 상황: event · guests · activity · theme (보이는 것만)
- 대안 의도 (단서가 1개라도 그 의도에만 쓰는 물건이면 적는다)
